## Досье первоисточника (этап 1)

### Общее (§4.2.2, стр. 202–208)

- Идея: заменить `X_i − μ0` в параметрических CUSUM (ур. 3.3, 3.4) на
  статистику подгруппы (`SN_t` или `SR_t`).
- Параметры схемы: `k > 0` — **референсное значение** (задаётся первым, обычно малое);
  `h > 0` — **интервал решения**, подбирается под номинальный `ARL_IC`.
  Выбор `(h,k)` — §3.2.2 (стр. 67) и Amin, Reynolds, Bakir (1995), табл. 5 (для `n = 10`).
- Карта CUSUM накапливает статистику во времени — класс «с памятью» (в отличие от
  Шухарта `SignChart`/`SignedRankChart` из §4.2.1).

### CUSUM-SN (знаки), §4.2.2.1, стр. 202–203

- Верхняя односторонняя: `SN_t^+ = max(0, SN_{t−1}^+ + SN_t − k)`, `SN_0^+ = 0`;
  сигнал при первом `t`, где `SN_t^+ ≥ h`.  **(ур. 4.7)**
- Нижняя односторонняя: `SN_t^− = min(0, SN_{t−1}^− + SN_t + k)`, `SN_0^− = 0`;
  сигнал при первом `t`, где `SN_t^− ≤ −h`.  **(ур. 4.8)**
- Двусторонняя: сигнал, если сработала любая из односторонних.
- `SN_i = 2T_i − n`, `T_i ~ Bin(n, p)`, `p = P(X_ij ≥ μ0)`; в IC `p = 0.5`.
- Контролирует **медиану** (любой параметр положения), требуется лишь непрерывность.

### CUSUM-SR (знаковые ранги), §4.2.2.4, стр. 205–206

- Верхняя: `SR_t^+ = max(0, SR_{t−1}^+ + SR_t − k)`, `SR_0^+ = 0`; сигнал `SR_t^+ ≥ h`. **(ур. 4.10)**
- Нижняя: `SR_t^− = min(0, SR_{t−1}^− + SR_t + k)`, `SR_0^− = 0`; сигнал `SR_t^− ≤ −h`. **(ур. 4.11)**
- Двусторонняя: как выше. `SR_i = 2T_i^+ − n(n+1)/2`, `T_i^+` — статистика
  знаковых рангов Уилкоксона. Распределение `SR_i` — из распределения `T_n^+`.
- Требуется **симметрия** распределения (как и для Шухарт-SR).
- Первоисточник: Bakir and Reynolds (1979).

### ⚠️ Расхождения / опечатки книги

| Место | Напечатано | Как надо | Подтверждение |
| --- | --- | --- | --- |
| Ур. 4.11, стр. 206 (нижняя CUSUM-SR) | `SR_t^− = min(0, SR_{t−1}^− + SR_t − k)` | `+ k` | Пример 4.9, стр. 237: `SR_1^− = min(0, SR_0^− + SR_1 + k)`; параллель с ур. 4.8 (SN) |

В коде использовать `+ k` для нижней ветви (как в рабочем примере), ссылку давать
на ур. 4.8/4.9 и отмечать расхождение с печатной формулой 4.11.

### Метод расчёта RL (§4.2.2.3, стр. 203–205; §4.2.2.4.3, стр. 206)

- **Марковская цепь:** `S_t^+ = min{h, max{0, S_{t−1}^+ + SN_t − k}}` (ур. 4.9);
  поглощающее состояние — сигнал. Аналогично для SR (ур. 4.12).
- **Симуляция:** 100 000 повторов; шаги — в книге (стр. 205, 207–208).
  SAS-программы: Appendix B, №3 (SN) и №4 (SR).

- Счётчики `N^+`, `N^−` — число последовательных периодов с ненулевой статистикой;

## Архитектура (этап 2) — принято, см. ADR-020

- **Решение:** `CusumSignChart` наследуется от `BaseControlChart` (единый API);
  семантика через `control_limits` (`CL=0`, `UCL=+h`, `LCL=−h`, ключи `k`, `h`).
  Знаковая статистика `SN_t` вынесена в `utils/statistics.py` и используется
  и `SignChart`, и `CusumSignChart`.
- **Фазы:**
  - **3a (ядро) — готово:** явные `k`, `h`; `SN_t⁺`, `SN_t⁻`, счётчики `N⁺`, `N⁻`;
    сигнал (первое срабатывание на сторону); `plot`; `get_summary`.
  - **3b (RL и дизайн) — далее:** распределение длины серии (Марков, ур. 4.9;
    проверка — пример 4.8) и/или симуляция; `ARL_IC`, `SDRL`, `MRL`; подбор `h`
    под `ARL_IC` (сверка с рис. 4.5: `n=10, k=6, h=4 → ARL_IC≈500`).
- **ADR:** ADR-020 (CUSUM-SN), ADR-022 (CUSUM-SR).

## Архитектура (этап 2 для SR) — принято, см. ADR-022

- **Решение:** `CusumSignedRankChart` повторяет схему ADR-020 (`BaseControlChart`,
  `control_limits = {CL=0, UCL=+h, LCL=−h, k, h}`). Знаково-ранговая статистика
  `SR_t` вынесена в `utils/statistics.py` (`signed_rank_statistic`,
  `signed_rank_details`) и используется и `SignedRankChart`, и
  `CusumSignedRankChart`.
- **Опечатка ур. 4.11** учтена: нижняя ветвь с `+k` (пример 4.9, стр. 237);
  в докстринге/тесте отмечено расхождение с печатной формулой.
- **Значения по умолчанию:** `k = 3`, `h = 8` (пример 4.9). Требуется
  симметрия распределения.
- **Фаза:** ядро (сигналы, `plot`, `summary`) — готово; RL (пример 4.10) — 3b.
