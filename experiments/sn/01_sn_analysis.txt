========================================================================
01. SN: точные FAR/ARL, Монте-Карло, время
    Скрипт: experiments/sn/sn_analysis.py
    Требуется: только Python (R не нужен)
========================================================================

ЦЕЛЬ
  Сопоставить границы a по правилам и проверить точные FAR/ARL методом
  Монте-Карло.

СОДЕРЖАНИЕ
  A. Границы a и FAR по правилам: exact, nearest(α = 0.05),
     npSPC(far = 0.0027), npSPC(far = 0.00135); n = 1..20.
  B. Сигнал и ARL при сдвиге δ = 0, 0.5, 1, 1.5, 2 σ; n = 16.
  C. FAR: теория vs Монте-Карло (m = 500 000); условия IC и δ = 1σ.
  D. Время расчёта.

ЗАПУСК
  cd $REPO
  poetry run python experiments/sn/sn_analysis.py

ОЖИДАЕМОЕ (n = 16)
  * exact a = 14 (FAR = 0.000519); npSPC(far = 0.0027) a = 12 (FAR = 0.004181).
  * exact = npSPC(far = 0.00135) при всех n; расхождение с
    npSPC(far = 0.0027) при n = 13, 16, 19.
  * MC согласуется с теорией: IC 0.000542 vs 0.000519.
