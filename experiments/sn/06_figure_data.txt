========================================================================
06. КООРДИНАТЫ ГРАФИКОВ И СТРОК ТАБЛИЦ ДЛЯ ОТЧЁТА
    Скрипт: experiments/sn/gen_figdata.py
    Требуется: только Python
========================================================================

ЦЕЛЬ
  Сгенерировать LaTeX-макросы (\def...) с координатами графиков и строками
  таблиц, используемыми в docs/reports/sn_verification.tex. Все значения считаются
  точно (биномиальные хвосты), поэтому отчёт не зависит от случайности.

ЧТО ПЕЧАТАЕТСЯ
  * \verACons, \verANp, \verANear — границы по правилам (n = 1..20);
  * \verOCBook, \verOCNp — вероятность сигнала при сдвиге (n = 16);
  * \verModeCons, \verModeNear — константа a по методам (n = 1..30);
  * \verFARCons, \verFARNear — достигнутый FAR по методам (n = 1..30);
  * \verModeTable — строки таблицы методов;
  * \verNearAbs14, \verNearMin14 — критерий «ближайший» при n = 14.

ЗАПУСК
  cd $REPO
  poetry run python experiments/sn/gen_figdata.py

ИСПОЛЬЗОВАНИЕ
  Вывод копируется в преамбулу docs/reports/sn_verification.tex (блок «Координаты
  графиков»). Затем отчёт пересобирается:
  cd docs && make snver
