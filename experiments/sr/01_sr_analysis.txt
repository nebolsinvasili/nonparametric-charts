ЦЕЛЬ
  Сопоставить границы a по правилам; проверить FAR методом Монте-Карло.

СОДЕРЖАНИЕ
  A. Границы a и FAR по правилам: exact, normal, npSPC-exact(far = 0.0027),
     npSPC-asym; n = 2..20.
  B. Сигнал при сдвиге δ = 0, 0.5, 1, 1.5, 2 σ (свёртка и Монте-Карло);
     n = 16, m = 500 000.
  C. FAR: теория vs Монте-Карло (IC); правила exact, normal, npSPC-exact.
  D. Время (включая ДП-свёртку при n = 30).

ЗАПУСК
  cd $REPO
  poetry run python experiments/sr/sr_analysis.py

ОЖИДАЕМОЕ (n = 16)
  * exact a = 110 (FAR = 0.002686); npSPC-exact(far = 0.0027) a = 108
    (FAR = 0.003357); расхождение при n ≥ 10.
  * normal совпадает с exact при n ≤ 10.
  * MC согласуется с теорией: IC 0.002778 vs 0.002686.
