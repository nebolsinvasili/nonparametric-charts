========================================================================
06. КООРДИНАТЫ ГРАФИКОВ И СТРОК ТАБЛИЦ ДЛЯ ОТЧЁТА (SR)
    Скрипт: experiments/sr/sr_gen_figdata.py
    Требуется: только Python
========================================================================

ЦЕЛЬ
  Сгенерировать LaTeX-макросы (\def...) с координатами графиков и строками
  таблиц, используемыми в docs/reports/sr_verification.tex. Все значения считаются
  точно (ДП-свёртка распределения SR, нормальные квантили), поэтому отчёт
  не зависит от случайности.

ЧТО ПЕЧАТАЕТСЯ
  * \vSRACons, \vSRASym, \vSRANear, \vSRANpExact, \vSRANpAsym — границы
    по режимам (n = 2..20);
  * \vSRFARCons, \vSRFARSym, \vSRFARNear — достигнутый FAR по режимам;
  * \vSRModeTable — строки таблицы режимов;
  * \vSROCBk, \vSROCNp — вероятность сигнала при сдвиге (n = 16, свёртка);
  * \vSRpmfFive — распределение SR в IC (n = 5);
  * \vSRTail5, \vSRTail10, \vSRTail14, \vSRTail20 — односторонний хвост;
  * \vSRNearAbs14, \vSRNearMin14 — критерий «ближайший» при n = 14.

ЗАПУСК
  cd $REPO
  poetry run python experiments/sr/sr_gen_figdata.py

ИСПОЛЬЗОВАНИЕ
  Вывод копируется в преамбулу docs/reports/sr_verification.tex (блок «Координаты
  графиков»). Затем отчёт пересобирается:
  cd docs && make srver
