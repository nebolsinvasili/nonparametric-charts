# Перевод книги Чакраборти (LaTeX)

Русский перевод книги Chakraborti & Graham (2019) *Nonparametric Statistical
Process Control* (Wiley). Лежит в этом же репозитории, чтобы перевод и
реализация методов шли синхронно: раздел книги → перевод → код → проверка.

- **Первоисточник:** `docs/ref/chakraborti_s_graham_ma_nonparametric_statistical_process_co.pdf`
- **Правило страниц:** печатная страница книги = PDF-страница книги − 22.
  В этом README и в `docs/reports/coverage_plan.md` — **печатные** страницы.
- **Единый реестр «перевод + реализация»:** `docs/reports/coverage_plan.md`.

## Структура

```text
book/
  document.tex          главный файл: преамбула, \include, приложения
  chapter-1.tex         гл. 1 «Обзор статистических концепций» (заготовка)
  chapter-2.tex         гл. 2 «Основы статистического контроля процессов»
  chapter-3.tex         гл. 3 «Параметрические ... карты» (готова)
  chapter-4.tex         гл. 4 «Непараметрические карты» (готова)
  fig-4.22.tex          панели a–c рис. 4.22 (подключается через \input)
  images/               рисунки fig-2.*, fig-3.*, fig-4.* (вырезаются из PDF книги)
  document.pdf          собранный PDF (коммитится)
  check_translation.py  контроль статуса (TODO, рисунки, объём)
  lint_tables.py        проверка таблиц (число колонок) и \footnote в \caption
  extract_figures.py    автоматическая вырезка рисунков из PDF книги
  Makefile              сборка и проверки
  glossary.md           глоссарий терминов (EN → RU → идентификатор в коде)
```

## Сборка

Требуется TeX Live с `babel-russian`, `T2A`, `amsmath`, `graphicx`, `booktabs`,
`multirow`, `longtable`, `tikz`, `chngcntr`, `hyperref`.

В преамбуле `document.tex` встроенное переключение языка babel в математике
отключено: русский текст в формулах набирается явным `\text{...}`, иначе babel
трактует точки и запятые внутри как знаки конца предложения и добавляет пробелы.

```bash
make -C book            # два прохода pdflatex + линтер таблиц + проверка статуса
make -C book check      # только проверка статуса
make -C book check-strict  # строго: нет рисунков/битые ссылки/таблицы = ошибка
make -C book figures    # вырезать рисунки 3.8–3.23 из PDF книги
make -C book clean      # убрать .aux/.log/.out/.toc/.synctex.gz
```

### Таблицы (`lint_tables.py`)

`pdflatex` сообщает о неверном числе колонок только как `Extra alignment tab`
в логе, причём без номера строки исходника, а `make -C book clean` лог удаляет.
Поэтому таблицы проверяются до сборки:

```bash
book/lint_tables.py          # ошибки (код возврата 1)
book/lint_tables.py --warn   # плюс предупреждения о ширине
```

Что проверяется: число колонок в преамбуле `tabular` против числа ячеек в
строках (с учётом `\multicolumn`, `*{n}{...}`, `@{}`); `\footnote` внутри
`\caption`; наличие файлов `images/...`.

**Правило при сборке таблиц из книги.** В книге сводные шапки часто
«плоские» (колонка «Sample» над всей таблицей, подразделы `(a)`, `(b)`, ...),
поэтому число колонок нужно считать по строке данных, а не по шапке.
Сводные шапки набираются через `\multicolumn` с `\cmidrule`; в преамбуле —
ровно столько колонок, сколько ячеек в строке данных. Пример — табл. 4.12
(5 колонок) и табл. 4.25/4.26 (11 колонок).

Рисунки глав 3 (3.8–3.23) и 4 (4.1–4.34) вырезаны автоматически
(`make -C book figures`), в PDF они больше не «draft»-рамки. Подробности —
в разделе «Рисунки из книги».

## Правила перевода

1. **Термины** — по `glossary.md`. При первом употреблении в главе термин
   даётся по-русски, английский оригинал — в скобках: «статистика для
   нанесения на карту (charting statistic)».
2. **Идентификаторы не переводятся**: имена методов и классов (`SignChart`,
   `CUSUM-SN`, `EWMA-SR`), обозначения (`SN_i`, `SR_i`, `k`, `h`, `FAR`,
   `ARL`) остаются как в книге и в коде.
3. **Формулы** — LaTeX, нумерация как в книге; `\label{eq:3.1}` и т. п.
   сохраняются, чтобы на них можно было ссылаться из отчётов и кода.
4. **Рисунки и таблицы** — номера как в книге (`fig-3.8`, `tab:3.12`).
   Если рисунка нет, он попадает в дефекты ниже, а не заменяется самодельным.
5. **Смысл не меняется.** Спорный или неудачный термин — в раздел «Спорные
   термины» в `glossary.md`, а не «молчаливая» правка.
6. **После главы** — обновить статус здесь и в `docs/reports/coverage_plan.md`,
   прогнать `make -C book check`. Проверка сверяет число `\todo` с
   `EXPECTED_TODO` в `check_translation.py`: пока глава не переведена, маркеры
   ожидаемы; после перевода ожидание надо уменьшить.

## Рисунки из книги

Фигуры в PDF книги векторные (растровых вставок нет), поэтому рисунки не
извлекаются как файлы, а вырезаются рендером страницы по подписям:

```bash
.venv/bin/python book/extract_figures.py --figures 3.8-3.23 --force
```

Алгоритм (`extract_figures.py`):

1. `pdftotext -bbox-layout` даёт координаты строк; подпись `FIGURE <гл>.<н>`
   задаёт низ рисунка.
2. Верх — конец последней полной строки основного текста выше подписи (или
   верх полосы набора, если рисунок в начале страницы); на странице с
   несколькими рисунками учитывается конец предыдущей подписи.
3. Полоса рендерится `pdftoppm` (200 dpi), белые поля подрезаются Pillow,
   добавляется отступ 12 px.
4. Если подпись помечена `(Continued)`, части с двух страниц склеиваются
   по вертикали — так собран рис. 3.19 (панели a–b и c–d).

Проверка результата: `--contact file.png` собирает контактный лист для
визуального контроля. Ручная правка границ — словарь `OVERRIDES` в начале
скрипта (координаты в пунктах PDF).

Для главы 4: `make -C book figures FIGURES=4.1-4.34`. Панели вроде
`4.22a`/`b`/`c` вырезаются в отдельные файлы `fig-4.22a.png` и т. д. и
подключаются вручную через `fig-4.22.tex` (у панелей свои подписи и метки).

## Как добавить главу

1. Создать `chapter-N.tex` с `\chapter{...}` и переведёнными разделами.
2. Подключить в `document.tex`: `\include{chapter-N.tex}`.
3. Положить рисунки в `images/` с именами `fig-N.x.png` — вручную или
   автоматически: `make -C book figures FIGURES=N.1-N.20`.
4. Обновить `EXPECTED_TODO` в `check_translation.py` (для новой главы — 0
   после полного перевода).
5. Обновить таблицу статуса здесь и `docs/reports/coverage_plan.md`.
6. `make -C book && make -C book check`.

## Известные дефекты

- Глава 1 — только заголовки.
- Глава 5 и приложения A/B не начаты.
- Сноска внутри `\caption` ломает сборку при наличии списка таблиц
  (`\caption@ydblarg`), поэтому примечания к таблицам даны строкой под
  заголовком (см. табл. 4.4). Проверяется `book/lint_tables.py`.
- Широкие формулы книги (например, ARL карты KL «2 из 2», §4.6.2) переносятся
  на две строки `aligned` — в одну строку формула вылезает за поля.
- В таблице 4.27 книги строки 16–20 повторяют строки 1–5; воспроизведено как есть.
- Библиография в `document.tex` закомментирована; `\cite` в тексте не
  используются, ссылки на литературу даны текстом.
