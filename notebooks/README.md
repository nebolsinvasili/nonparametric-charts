# Ноутбуки

Четыре учебных ноутбука, собранных по **одному каркасу**:

| Файл | Карта | Что внутри |
| --- | --- | --- |
| `sign_chart_analysis.ipynb` | Shewhart-SN | знаки, границы `±a`, три подхода к выбору `a` |
| `signed_rank_chart_analysis.ipynb` | Shewhart-SR | знаковые ранги, проверка симметрии, выбор `a` |
| `cusum_sign_analysis.ipynb` | CUSUM-SN | накопление, `(k, h)`, `ARL(h)`, OC-кривые |
| `cusum_signed_rank_analysis.ipynb` | CUSUM-SR | то же для знаковых рангов |

Ноутбуки — **учебные**: показывают формулы и код, а не заменяют тесты.
Проверка API — `tests/`, численные примеры книги — `examples/`.

## Единая структура

Все четыре файла имеют одинаковые разделы:

1. **Заголовок и источник** — раздел и печатные страницы книги.
2. **Импорты и настройка** — `sys.path`, единый LaTeX-стиль, палитра.
3. **Теория (минимум)** — постановка, статистика, границы/сигнал; формула в
   LaTeX и строкой кода.
4. **Загрузка `data.csv`** — `DataLoader` → `DataPreprocessor`, `n` = число
   столбцов, `μ₀` фиксируется по исходным данным.
5. **Проверка данных** — пропуски, квартили, выбросы по правилу Тьюки
   (IQR 1.5), для SR — ещё и симметрия.
6. **Подбор параметров разными методами** — сравнение подходов, таблица и
   графики, комментарий с выбором.
7. **Построение карты** — границы, график, найденные сигналы, разбор.
8. **Те же шаги на очищенных данных** — выбросы ограничиваются заборами
   IQR (винзоризация; форма таблицы и `n` сохраняются), затем повторяются
   проверка, подбор и карта.
9. **Сравнение и итог** — сводная таблица «исходные / без выбросов» и выводы.

Порядок разделов и их названия одинаковы во всех файлах; различаются только
методы и формулы конкретной карты.

## Запуск

```bash
cd notebooks
jupyter lab
```

Важно: ноутбуки добавляют `../src` в `sys.path`, поэтому запускать их нужно
**из каталога `notebooks/`**. При запуске из корня репозитория импорт может
взять установленную версию пакета или не найти `src`.

Если пакет установлен (`poetry install` / `pip install .`), путь `../src`
всё равно указывает на локальную версию — это удобно для разработки.

### Kernel

Выберите kernel окружения, в котором установлены зависимости:

- Poetry: `poetry run python -m ipykernel install --user --name nonparametric-charts-py`;
- либо kernel `.venv` из проекта;
- в текущих файлах metadata может указывать `python3` — это нормально,
  если в этом kernel доступны `numpy`, `pandas`, `scipy`, `matplotlib`.

Проверка из notebook:

```python
import sys
print(sys.executable)
import nonparametric_charts
print(nonparametric_charts.__file__)
```

Путь должен указывать на `src/nonparametric_charts` (при запуске из
`notebooks/`) либо на установленный пакет.

## Полный прогон

В Jupyter: `Kernel → Restart & Run All`.

Или из командной строки:

```bash
cd notebooks
jupyter nbconvert --to notebook --execute sign_chart_analysis.ipynb \
    --output /tmp/sign_executed.ipynb
```

Ожидаемо: все ячейки выполняются без ошибок. Предупреждения `findfont` или
`LaTeX` не критичны, если графики строятся; ошибки импорта — критичны.

## Проверка данных

Общие функции вынесены в `src/nonparametric_charts/utils/data_quality.py`:

| Функция | Назначение |
| --- | --- |
| `summarize_dataset(data)` | размеры, пропуски, квантили, асимметрия, заборы IQR |
| `find_iqr_outliers(data, k=1.5)` | таблица выбросов: подгруппа, столбец, значение |
| `winsorize_outliers(data, k=1.5)` | винзоризация: поджать выбросы к заборам IQR + журнал |
| `replace_outliers_with_subgroup_median(data)` | альтернатива: замена медианой подгруппы (строки) + журнал |

Правило Тьюки: значение вне `[Q1 − 1.5·IQR; Q3 + 1.5·IQR]` считается
выбросом. В ноутбуках используется **винзоризация**: значение заменяется
ближайшим забором. Это сохраняет `n` и решётку статистики, не берёт значение
из чужой ячейки и не меняет знак отклонения, если заборы не пересекают `μ₀`.

Альтернатива — замена медианой подгруппы: она держит уровень строки, но может
перенести наблюдение через `μ₀` и создать искусственный сигнал.

## Результаты и артефакты

Ноутбуки показывают графики inline; исполненные копии не коммитятся.
Коммитится исходный ноутбук с очищенными выходами, если это принято в
текущей задаче.

Перед коммитом:

```bash
jupyter nbconvert --clear-output --inplace notebooks/*.ipynb
```

Не удаляйте outputs, если они нужны для проверки в конкретной задаче;
уточните ожидаемый формат.

## Проверка стиля

Графики должны использовать `apply_minimal_latex_style()` и палитру проекта
(`ACCENT`, `INK`, `PALETTE`, ...). Проверка соответствия каркасу и стилю —
навык `style-check`:

```bash
# из корня репозитория
poetry run python -c "from nonparametric_charts.utils.plot_style import apply_minimal_latex_style; apply_minimal_latex_style()"
```

Если график выглядит иначе, чем в отчёте, проверьте:

- вызван ли `apply_minimal_latex_style()`;
- не переопределены ли `rcParams` после вызова;
- используется ли `usetex` (по умолчанию `True`; при недоступном TeX —
  `apply_minimal_latex_style(usetex=False)`).

## Частые проблемы

**`ModuleNotFoundError: nonparametric_charts`** — запустите Jupyter из
`notebooks/` или установите пакет.

**`FileNotFoundError` для данных** — проверьте относительный путь; ноутбуки
рассчитаны на `cwd = notebooks/`.

**Kernel не видит зависимости** — выберите kernel Poetry-окружения или
установите `ipykernel` в нужное окружение.

**Долгий CUSUM-ноутбук** — точный RL при больших `ARL` может считаться
секунды; это ожидаемо. Для быстрой проверки уменьшите `max_t`/сетку, но не
меняйте формулы.

**Графики без кириллицы** — проверьте шрифты и `apply_minimal_latex_style()`;
в проекте подписи на русском, поэтому нужен шрифт с кириллицей.

**LaTeX-ошибка `Unicode character ₀`** — в подписях графиков используйте
mathtext (`$FAR_0$`), а не Unicode-индексы; таблицы DataFrame могут содержать
Unicode.
