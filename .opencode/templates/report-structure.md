# Шаблон отчёта: верификация контрольной карты

Копируй структуру ниже для нового отчёта `docs/reports/<chart>_verification.tex`.
Живые образцы: `sn_verification.tex`, `sr_verification.tex`,
`cusum_verification.tex`. Полные правила — `rules/sources.md`,
`rules/plot-style.md`, `rules/reference.md`.

Сборка и проверка — из `docs/reports/`:

```bash
make <chart>     # собрать один отчёт (двойной pdflatex)
make check       # ошибки/undefined/overfull по всем логам
```

---

## 1. Преамбула (единая для всех отчётов)

```latex
% !TEX program = pdflatex
% <Одна фраза: что и с чем сверяется>.
% Первоисточники: <авторы, годы>. Сборка: pdflatex (T2A + babel russian).
\documentclass[11pt,a4paper]{article}
\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\usepackage[margin=2.4cm]{geometry}
\usepackage{amsmath,amssymb}
\usepackage{pgfplots}\pgfplotsset{compat=1.17}
\usepackage{booktabs,array,graphicx,xcolor,listings,caption,enumitem}
\usepackage[hidelinks]{hyperref}
% цвета: accent #2E86AB, alert #B22222, third #3C6E47, softgray #808080
% \lstset: \ttfamily\small, breaklines, frame=single, softgray
% \emergencystretch=1.5em; \captionsetup{font=small,labelfont=bf}
\input{<chart>_macros}   % координаты графиков (генерируются скриптом)
```

Правила:
- графики — только через макросы `docs/reports/<chart>_macros.tex`,
  генератор — `experiments/<chart>/NN_gen_figdata.py`, цель в `Makefile`;
- в `lstlisting` **не писать кириллицу** (ошибка UTF-8 в listings) —
  комментарии в коде на английском;
- ссылки на книгу — с разделом и **печатной** страницей.

## 2. Обязательные разделы (порядок)

1. **Аннотация** — что проверялось, главные числа, открытые расхождения.
2. **Сокращения** — английское написание + русское пояснение.
3. **Введение** — зачем карта, что именно верифицируется, три уровня
   проверки (численно / примеры книги / внешняя реализация).
4. **Математические основы** — определения, формулы с номерами книги,
   распределения и моменты, правило сигнала, RL/ARL/SDRL/MRL, метод
   расчёта RL (марковская цепь, renewal, МК, приближения), дизайн.
   Опечатки и расхождения книги — отдельной таблицей.
5. **Программная реализация** — дерево модулей, классы и API, ключевые
   функции, фазы I/II, сложность и таблица времени.
6. **Реализации на языке R** — что найдено, что реализует, дефекты
   чужого кода (с доказательством), прочие пакеты.
7. **Сопоставление** — сводная таблица «реализация / статистика /
   границы / особенности» + 3–5 ключевых наблюдений.
8. **Вычислительный эксперимент** — примеры книги (таблица), проверка
   согласованности методов, OC-кривые, дизайн, кросс-валидация
   Python↔R, производительность, открытые расхождения.
9. **Результаты и рекомендации** — что даёт реализация, что делать
   практику, направления развития.
10. **Заключение** — 1–2 абзаца без новых чисел.
11. **Приложение** — точные команды воспроизведения, привязка формул к
    страницам, библиография.

## 3. Числа и воспроизводимость

- Каждое число в тексте должно воспроизводиться скриптом из
  `experiments/`; в приложении — команда запуска.
- Результаты опытов сохранять в `results/experiments/<chart>_*.txt`
  (скрипт печатает в консоль **и** пишет файл), графики — `*.png`.
- Книжные и «золотые» значения — в `tests/`, отчёт ссылается на них.
- Расхождение с книгой оформлять как открытое: подтверждение двумя
  независимыми методами, без подгонки кода.

## 4. Чек-лист перед сдачей

- [ ] `make <chart>` без ошибок; `make check` — 0 errors/undefined.
- [ ] Overfull hbox < 8 pt (крупные — переформулировать или сузить
      таблицу).
- [ ] Все рисунки собираются из макросов, макросы не правятся вручную.
- [ ] У каждой формулы — номер книги и печатная страница.
- [ ] Таблицы: `booktabs`, `\small`, ширина ≤ `\textwidth`.
- [ ] Примеры книги воспроизводятся; расхождения объяснены.
- [ ] Обновлены `docs/reports/<chart>_plan.md`, `memory/tasks-completed.md`,
      при необходимости `memory/book-map.md`.
