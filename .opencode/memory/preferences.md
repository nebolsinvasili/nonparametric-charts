# Предпочтения пользователя

- **Старые версии не удалять.** Сохранять код, ветки, worktree, теги и
  артефакты, фиксирующие прежние результаты. Удаление — только по явному
  разрешению пользователя.
- **Подробная документация.** Для каждого нового модуля, опыта, отчёта и
  ноутбука нужен README: назначение, алгоритм, команда запуска,
  входы/выходы и ожидаемый результат. Это нужно для быстрого
  воспроизведения результатов.
- **Проверяемость.** В инструкциях указывать точные команды, окружение и
  контрольные числа; результаты опытов не подгонять под книгу.
