# Notebook Build — сборка ноутбука

Процедура создания/обновления ноутбука в `notebooks/` по жёсткому каркасу.

## Предпосылки

- Прочитать `rules/notebook-style.md` (порядок разделов) и `rules/plot-style.md`.
- Свериться с книгой (навык `book-lookup`) — раздел и печатные страницы.
- Шаблон: `templates/notebook-structure.md`.

## Шаги

1. **Источник.** Определи раздел книги для темы (см. `memory/book-map.md`) и выпиши
   ссылку: `Chakraborti & Graham (2019), § ..., стр. ...`.
2. **Каркас.** Разверни разделы шаблона:
   1. Заголовок и источник → 2. Импорты и настройка → 3. Теория →
   4. Формулы (LaTeX + код) → 5. Реализация → 6. Разбор кода → 7. Логика →
   8. Графики → 9. Проверка по книге → 10. Итог.
3. **Импорты.** Первая кодовая ячейка:

   ```python
   import sys; sys.path.append('..')
   import numpy as np, pandas as pd
   from nonparametric_charts.utils.plot_style import apply_minimal_latex_style
   apply_minimal_latex_style()
   ```

4. **Формулы.** Каждую ключевую формулу дай дважды: в markdown (`$$...$$`) и в
   коде (строка из `src/`). Кириллицу — вне `$...$`.
5. **Данные/коэффициенты.** `'../data/data.csv'`, коэффициенты
   `'../src/nonparametric_charts/utils/coefficients.json'`. Логику не дублировать —
   вызывать код из пакета `nonparametric_charts`.
6. **Графики.** Стиль из `plot_style`; подписи и легенды по-русски.
7. **Проверка.** Численный пример сверь с примером/таблицей из книги; расхождения
   разбери. При необходимости открой раздел через `book-lookup page <стр>`.
8. **Прогон.** Запусти ноутбук из `notebooks/` (kernel `nonparametric-charts-py`) и убедись, что
   ячейки выполняются сверху вниз без ошибок.
9. **Память.** Обнови `memory/tasks-completed.md` и, если решение архитектурное,
   `memory/architecture-decisions.md`.

## Результат

Ноутбук, где читается цепочка: откуда формула → как реализована → почему так →
как выглядит график → совпадает ли с книгой.
