# Book Lookup — сверка с первоисточником

Процедура точечной сверки с книгой Chakraborti & Graham (2019) перед реализацией
или при сомнении в методе.

## Когда использовать

- Перед реализацией нового метода/карты или изменением формул.
- Когда численный результат расходится с кодом.
- Всегда, когда «непонятно» — это сигнал открыть книгу (см. `rules/sources.md`).

## Шаги

1. Сформулируй, **что именно** ищешь: название метода, статистику, константу
   (например, «Signal Chart», «signed-rank statistic», «ARL», «FAR»).
2. Найди страницы. Основной вход — скрипт (пересчитывает печатные страницы):

   ```bash
   python .opencode/skills/book-lookup/scripts/lookup.py search "Shewhart Sign"
   python .opencode/skills/book-lookup/scripts/lookup.py search "signed-ranks" --ctx 2
   python .opencode/skills/book-lookup/scripts/lookup.py page 189 --span 8
   ```

   Важно: **печатная страница = PDF-страница − 22**. Скрипт делает пересчёт сам;
   не подставляй печатные номера в `pdftotext -f`.
3. Открой раздел целиком (не одну строку) и выпиши:
   - определение статистики и её распределение в IC;
   - контрольные границы и константу (`a`, `c`, ...);
   - правило сигнала;
   - характеристики: FAR, ARL, MRL и т. п.
4. Сверь с текущим кодом (`src/`): совпадает ли формула, границы, правило.
5. Если в книге ссылка на первоисточник (статья, теорема) — при необходимости
   перейди к нему; вторичный русский источник — `docs/Klyachkin_...pdf`.
6. Зафиксируй ссылку в коде/докстринге в формате
   `Chakraborti & Graham (2019), § 4.2.1.1, стр. 189–196`.
7. Если нашёл расхождение — обнови `memory/architecture-decisions.md`
   (что и почему изменено).

## Карта разделов

См. `memory/book-map.md` (тема → раздел → печатная страница).

## Ожидаемый результат

- Раздел и диапазон печатных страниц.
- Формулы/константы дословно из книги.
- Вывод: код соответствует книге или требует правки (с указанием, какой).
