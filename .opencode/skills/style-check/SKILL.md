# Style Check — проверка стиля

Чек-лист перед сдачей графиков и ноутбуков.

## Графики (rules/plot-style.md)

- [ ] Вызван `apply_minimal_latex_style()` (или `BaseControlChart._setup_style()`).
- [ ] Шрифт serif, математика — mathtext `cm`; кириллица **вне** `$...$`.
- [ ] Верхняя и правая рамки сняты (`despine`).
- [ ] Сетка отсутствует; если есть — тонкая пунктирная, `alpha <= 0.3`.
- [ ] Линии тонкие, без заливок под кривыми; зоны — без заливки (`fill_zones=False`).
- [ ] Маркеры мелкие; нарушения — единый красный акцент.
- [ ] Легенда без рамки; нет «плашек» (`bbox`) за каждой точкой.
- [ ] Подписи осей/заголовок присутствуют; единицы измерения указаны.

## Ноутбук (rules/notebook-style.md)

- [ ] Есть источник (раздел + печатные страницы) в первой markdown-ячейке.
- [ ] Разделы идут по каркасу: теория → формулы → код → разбор → логика → графики
      → проверка по книге → итог.
- [ ] Каждая ключевая формула дана и в LaTeX, и в виде кода.
- [ ] Логика не дублируется — вызывается из `src/`.
- [ ] Численный пример сверен с книгой; расхождения объяснены.
- [ ] Ноутбук выполняется сверху вниз без ошибок.

## Как проверить быстро

```bash
# стиль-настройки в коде/ноутбуках
grep -rn "apply_minimal_latex_style\|rcParams" src/ notebooks/ | head
# прогон ноутбука (из notebooks/)
poetry run jupyter nbconvert --to notebook --execute <файл>.ipynb
```

**Правило нулевой терпимости:** стилевые замечания устраняются до сдачи, а не
«потом».
