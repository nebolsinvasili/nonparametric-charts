# Стиль графиков: минималистичный LaTeX

Цель — чистый научный вид в духе LaTeX (Computer Modern), без «мусора» (chartjunk).
Единая точка входа — `src/nonparametric_charts/utils/plot_style.py::apply_minimal_latex_style()`.

## Правила

- **Всегда** вызывать `apply_minimal_latex_style()` (или `plot_style.apply(...)`)
  до построения графиков. В классах это делает `BaseControlChart._setup_style()`.
- **Шрифт:** serif (`DejaVu Serif` / `Latin Modern Roman` / `Computer Modern Roman`).
  Математика — `mathtext.fontset = 'cm'` (Computer Modern), т. е. `$...$` выглядит
  как в LaTeX.
- **Кириллица:** русский текст тоже набирается как формула — через
  `math_text('...')` (при `usetex=True` это `$\text{...}$`, при `usetex=False` —
  `$\mathrm{...}$`). Внешний LaTeX подключает `T2A`, `utf8`, `babel russian`.
- **`usetex=True` по умолчанию** (единый Computer Modern, включая кириллицу).
  Если TeX недоступен — `apply_minimal_latex_style(usetex=False)` (mathtext,
  кириллица через DejaVu Serif).
- **Оси:** скрывать верхнюю и правую рамки (`despine`), тики наружу, тонкая рамка,
  `axes.edgecolor` тёмно-серый.
- **Сетка:** по умолчанию **нет**. Если нужна — тонкая пунктирная, `alpha <= 0.3`.
- **Линии:** тонкие (`linewidth ~ 1.2`), без заливок под кривыми.
- **Маркеры:** мелкие (`markersize = DATA_MARKER_SIZE = 4`), акцентный цвет, без
  декоративных «плашек» и теней. Маркер сигнала/нарушения — `scatter` с
  `s = SIGNAL_MARKER_SIZE = 2 · DATA_MARKER_SIZE**2` (вдвое больше по площади).
- **Цвет:** только семантические роли из `plot_style` (см. таблицу ниже).
  «Сырые» строки `'red'`, `'green'`, `'crimson'`, `'darkorange'`, hex-коды
  в картах, примерах и ноутбуках **запрещены**. Нарушения — единый `ALERT`.
  Границы — сдержанный `LIMIT`, предупреждающие — светлее (`WARNING`).
  Зоны (A/B/C) — тонкими линиями; заливка — только `ZONE_FILL` при
  `fill_zones=True`.
- **Легенда:** в рамке, как информационный блок (`frameon=True`, белый фон,
  `edgecolor=ZONE_LINE`), компактная: две колонки, уменьшенные отступы,
  `loc='best'` — ставится в свободное место. Блок данных (μ₀, n, m, …) —
  в **правом верхнем углу** (`data_legend`), «как есть». Прозрачный патч под
  ним не даёт `loc='best'` поставить легенду поверх блока.
- **Заголовок:** по центру, обычного размера, **без жирного** (`fontweight` не
  задавать вручную).
- **Размеры:** брать из rcParams; не хардкодить `fontsize=12/13` в `plot()`.
- **Математика:** все символы, параметры, числа и русский текст — в mathtext
  (`$...$`). Латинские сокращения — `\mathrm{}` (`\mathrm{CL}`, `\mathrm{FAR}`),
  русские слова — через `math_text()` (`\text{...}` при usetex).
  Подписи осей/заголовки собираются из math-сегментов.
- **Пропорции:** `figure.figsize ≈ (10, 5)`, `savefig.dpi = 300`, `bbox='tight'`.
- **Ничего лишнего:** убрать белые «плашки» (`bbox`) за каждой точкой; значения —
  только там, где они реально нужны.

## Единство карт Шухарта и CUSUM

Оформление `plot()` у всех карт проекта **одно** (эталон — CUSUM):

- данные — линия с маркерами (`'-o'`, `linewidth=1.2`,
  `markersize=DATA_MARKER_SIZE`), а не отдельные «точки + бледная ломаная»;
  сигналы/нарушения — `scatter(s=SIGNAL_MARKER_SIZE, color=ALERT)`;
- подписи значений — через `annotate_values(ax, x, y, ...)`: **над** точкой при
  `y ≥ 0` и **под** ней иначе, одним знаком после запятой (`.1f`), цвет `INK`.
  Смещение `offset` задаётся **в типографских пунктах** (по умолчанию `(0, 4.0)`),
  а не в единицах данных: иначе на карте с малым размахом (например, 4.1, где
  `|SN| ≤ 1`) подписи «улетают» от точек. Для двухветвевых CUSUM — `side='above'`
  / `side='below'` и `mask`, чтобы совпадающие нули подписывались один раз;
- запас по `y` — `y_low − 0.05·span` … `y_high + 0.25·span`, чтобы блок данных
  в правом верхнем углу не наползал на точки и границы;
- правый отступ по `x` — `+0.5`; больше (`+3.2`) — только если включены подписи
  зон (`show_zones=True`);
- зоны A/B/C (линии и подписи) **по умолчанию выключены**
  (`show_zones=False`) — как в CUSUM; включаются явно;
- размер фигуры по умолчанию — `(13, 7)`.

## Семантическая палитра

| Роль | Константа | Цвет | Назначение |
| --- | --- | --- | --- |
| текст/оси/точки | `INK` | `#1A1A1A` | подписи, тики, нейтральные точки |
| акцент данных | `ACCENT` | `#2E86AB` | линия/точки данных |
| сигнал | `ALERT` | `#B22222` | нарушения, выход за границы |
| центр | `CENTER` | `#808080` | CL |
| границы | `LIMIT` | `#8C4B3F` | UCL/LCL, `±a`, `±h` |
| предупреждение | `WARNING` | `#B5857B` | UWL/LWL |
| зоны | `ZONE_LINE` / `ZONE_FILL` | `#B3B3B3` / `#ECECEC` | границы/заливка зон |
| сетка | `GRID` | `#C8C8C8` | сетка (по умолчанию выключена) |

`PALETTE` — согласованный набор для сравнений (не для сигналов).
Дополнительные серии (например, нижняя ветвь CUSUM) берутся из `PALETTE`.

## Палитра и помощники

`plot_style` предоставляет:
- `apply_minimal_latex_style(usetex=True, font_serif=None, figsize=(10, 5))`;
- `hline(ax, y, role, label=None, ...)` — горизонтальная линия в стиле роли;
- `annotate_values(ax, x, y, *, mask=None, side='auto', offset=(0, 4.0),
  fmt='{:.1f}', ...)` — подписи значений у точек в едином стиле (смещение — в
  пунктах, не зависит от масштаба оси);
- `math_text(text)` — обернуть текст (включая кириллицу) в math-режим;
- `despine(ax, *, left=True, bottom=True)` — снять верх/право;
- константы ролей, `DATA_MARKER_SIZE`, `SIGNAL_MARKER_SIZE` и `PALETTE`
  (см. таблицу).
