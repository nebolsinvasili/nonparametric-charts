# Стиль графиков: минималистичный LaTeX

Цель — чистый научный вид в духе LaTeX (Computer Modern), без «мусора» (chartjunk).
Единая точка входа — `src/utils/plot_style.py::apply_minimal_latex_style()`.

## Правила

- **Всегда** вызывать `apply_minimal_latex_style()` (или `plot_style.apply(...)`)
  до построения графиков. В классах это делает `BaseControlChart._setup_style()`.
- **Шрифт:** serif (`DejaVu Serif` / `Latin Modern Roman` / `Computer Modern Roman`).
  Математика — `mathtext.fontset = 'cm'` (Computer Modern), т. е. `$...$` выглядит
  как в LaTeX.
- **Кириллица:** держать русский текст **вне** math-режима (`$...$` не рендерит
  кириллицу). `mathtext` использовать только для формул; подписи осей/заголовки —
  обычным текстом. Для кириллицы нужен serif-шрифт с её поддержкой (DejaVu Serif).
- **`usetex=False` по умолчанию** (нет внешней зависимости, кириллица не ломается).
  Включать `usetex=True` — только по явной просьбе и для англоязычных подписей.
- **Оси:** скрывать верхнюю и правую рамки (`despine`), тики наружу, тонкая рамка,
  `axes.edgecolor` тёмно-серый.
- **Сетка:** по умолчанию **нет**. Если нужна — тонкая пунктирная, `alpha <= 0.3`.
- **Линии:** тонкие (`linewidth ~ 1.2`), без заливок под кривыми.
- **Маркеры:** мелкие (`markersize ~ 4.5`), контрастный акцент, белая окантовка.
- **Цвет:** сдержанная палитра — чёрный/серый + один акцент. Нарушения — единый
  красный акцент. Зоны (A/B/C) — тонкими линиями; **без заливки** (`fill_zones=False`).
- **Легенда:** без рамки (`legend.frameon = False`), компактная.
- **Заголовок:** по центру, обычного размера, без жирного крика (по возможности).
- **Пропорции:** `figure.figsize ≈ (10, 5)`, `savefig.dpi = 300`, `bbox='tight'`.
- **Ничего лишнего:** убрать белые «плашки» (`bbox`) за каждой точкой; значения —
  только там, где они реально нужны.

## Палитра и помощники

`plot_style` предоставляет:
- `apply_minimal_latex_style(usetex=False, font_serif=None, figsize=(10, 5))`;
- `despine(ax, *, left=True, bottom=True)` — снять верх/право;
- `PALETTE` / `ACCENT` / `VIOLATION` — согласованные цвета.

## Проверка

Навык `style-check` — чек-лист перед сдачей графика.
